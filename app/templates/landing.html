What we look for

Rules-file backdoors

Invisible Unicode, instruction overrides, concealment ("don't tell the user"), encoded payloads and hidden HTML comments in CLAUDE.md, AGENTS.md, .cursorrules, copilot-instructions and SKILL.md.

MCP supply chain

Unpinned npx -y servers, git/tarball installs, pipe-to-shell launchers, privileged Docker, plaintext remote servers and credentials in URLs or args.

Tool poisoning

Hidden <IMPORTANT> instructions in tool descriptions, cross-tool shadowing, side-channel parameters and duplicated tool names in MCP manifests.

Over-privileged agents

bypassPermissions, Bash(*), Codex danger-full-access, Gemini YOLO, auto-approved MCP tools and sub-agents that inherit every tool.

Exfiltration & persistence

Hooks that phone home, API base-URL hijacks, instructions to read ~/.ssh or .aws/credentials, and edits to shell profiles or agent config.

Agents in CI

Workflows that run Claude/Codex/Gemini on issue comments or pull_request_target with untrusted text in the prompt and write-all tokens.
